**TAA Software – Front-end Preview**

TAA Software is an HR & Payroll ERP. This folder contains the front-end only
first version: a login page, a registration page and a dashboard with the full HR & Payroll menu.

There is no backend and no database yet. Nothing is saved
and the menu modules do not open any pages. The goal of this
version is to show the look, layout and navigation of the final product.
